= 术语和定义
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
计费首选项控制NetApp Console如何处理您的许可证和订阅的付款、发票和续订行为。您可以在以下两个级别之一设置偏好：

* *全球* — 适用于直接许可、市场订阅和Keystone订阅。
* *按订阅计费* — 仅适用于特定市场或直接许可合同。


账单来源可以是以下几种：

* *市场订阅* — 计费通过 AWS Marketplace、Azure Marketplace 或 Google Cloud Marketplace 进行。您可以选择云市场提供的计费帐户、地区和续订选项。
* *直接许可* — 计费通过NetApp进行。您可以在NetApp Console中管理许可证密钥、发票联系人和自动续订。
* * Keystone订阅* — 账单将通过您的Keystone协议进行结算。您可以在NetApp Console中管理发票收件人和成本中心标签。




== 权限

您需要 *Account Admin* 或 *Billing Admin* 角色才能更改账单偏好设置。操作员可以查看偏好设置，但不能修改它们。



== 设置账单偏好

计费偏好设置可让您： - 在所有服务中强制使用单一发票联系人列表， - 将使用情况与成本中心对齐， - 管理自动续订和到期通知， - 确保新的Cloud Volumes ONTAP (CVO) 系统继承正确的计费帐户。



= 账单字段



== 市场领域

* *Marketplace provider* — AWS、Azure 或 Google Cloud。
* *账单账户/订阅 ID* — 要收费的云账单账户。
* *合约期限* — 期限长度和续约行为。




= 计费选项和定义



== 条款和选项

* **NetApp 许可证优先** — 根据有效 NetApp 许可证开具账单。额外的使用转移到市场。
* **仅限 Marketplace 订阅** — 所有使用情况均通过 marketplace 合约收费。
* **PAYGO (Pay-As-You-Go)** — 按实际使用量计费的灵活订阅。
* **年度合约** — 固定期限的市场订阅。
* **自动续订** — 到期时自动续订合同。
* **自定义 CVO 配置** — 用于映射每个云提供商的多个订阅的高级模式。
* **直接许可证** — NetApp 管理的许可证，在市场容量之前使用。
* **超大规模** — AWS、Azure 或 Google Cloud 提供商。
* **确认更改对话框** — 在应用更新之前显示，以防止意外账单更改。




== 典型配置路径

| 场景 | 推荐的计费选项 | |-----------|-----------------------------| | 使用购买的 NetApp 容量 | NetApp 许可证优先 | | 仅使用市场合同 | 仅市场订阅 | | 在一个云提供商下计费多个项目 | 启用自定义 CVO 配置 | | 恢复为默认计费 | 禁用自定义 CVO 配置 |
